# LeetCode 144 二叉树的前序遍历

## 题目
给你二叉树的根节点 `root`，返回其节点值的 **前序遍历** 结果。
前序顺序：**根 → 左 → 右**。

## 解法：递归（C 语言）

```c
void preorder(struct TreeNode* root, int* res, int* resSize) {
    if (root == NULL) {
        return;
    }
    res[(*resSize)++] = root->val;
    preorder(root->left, res, resSize);
    preorder(root->right, res, resSize);
}

int* preorderTraversal(struct TreeNode* root, int* returnSize) {
    int* res = malloc(sizeof(int) * 2000);
    *returnSize = 0;
    preorder(root, res, returnSize);
    return res;
}
```

## 思路要点
- 前序遍历顺序：**根 → 左 → 右**，所以先访问当前节点 `root->val`，再递归左子树、右子树。
- `res` 是结果数组，`resSize` 是已存入元素个数，通过指针 `*resSize` 在递归各层间共享。
- `res[(*resSize)++] = root->val`：先取 `*resSize` 作下标存入当前值，再把计数器 +1；括号保证先解引用再自增。
- `returnSize` 用指针传递，使递归里对计数器的修改能带回主函数，最终 `*returnSize` 等于真实节点总数（LeetCode 要求调用方拿到这个长度来正确读取数组）。
- `malloc(2000)` 是示例容量，题目约束节点数 ≤ 100，足够；面试中更严谨可先遍历求节点数或动态扩容。

## 复杂度
- 时间 O(n)：每个节点恰好访问一次。
- 空间 O(n)：递归调用栈（最坏退化为链状树时深度 = n）+ 输出数组 O(n)。
