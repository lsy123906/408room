# LeetCode 145 二叉树的后序遍历

## 题目
给你二叉树的根节点 `root`，返回其节点值的 **后序遍历** 结果。
后序顺序：左 → 右 → 根。

## 解法：递归（C 语言）

```c
void postorder(struct TreeNode *root, int *res, int *resSize) {
    if (root == NULL) {
        return;
    }
    postorder(root->left, res, resSize);
    postorder(root->right, res, resSize);
    res[(*resSize)++] = root->val;
}

int *postorderTraversal(struct TreeNode *root, int *returnSize) {
    int *res = malloc(sizeof(int) * 2001);
    *returnSize = 0;
    postorder(root, res, returnSize);
    return res;
}
```

## 思路要点
- 后序遍历顺序：**左 → 右 → 根**，所以先递归遍历左子树、右子树，最后才把当前节点值 `root->val` 写入结果（代码里 `res[...] = root->val` 放在两个递归调用之后）。
- `resSize` 通过指针在递归各层间共享，`res[(*resSize)++] = root->val` 先取下标存值再计数 +1，最终 `*returnSize` 为节点总数。
- 与前序（144）唯一区别是**访问根节点的时机**：前序最开始访问，后序放最后。中序（94）则是夹在左右之间。
- `malloc(2001)` 为示例容量，题目约束节点数 ≤ 100，足够。

## 复杂度
- 时间 O(n)：每个节点访问一次。
- 空间 O(n)：递归调用栈（最坏链状树深度 = n）+ 输出数组 O(n)。
